# Shader Breakdown 20 — Procedural City via Repetition (the "structure machine")

A procedural city is the purest demonstration of the Chapter 11 "structure machine": **a single box primitive + repetition + a little per-cell variation = an entire skyline.** This is a fundamentally *exact SDF* construction (isometries + box), so it renders cleanly and efficiently — the "infinite city" style.

## 1. The fragment (reconstructed key parts)

```glsl
float map(vec3 p){
    // repeat into a grid of city blocks
    vec3 q = mod(p + 5.0, 10.0) - 5.0;   // centered repetition, cell size 10

    // building height varies per cell
    float h = 1.0 + 4.0 * hash(floor((p+5.0)/10.0));   // per-block height
    q.y -= 0.0;                                        // keep base at ground

    // the building: a box of varying height
    float d = sdBox(q, vec3(2.0, h, 2.0));
    return d;
}
```

## 2. Mathematics

### 2.1 The repetition transform

`mod(p + a/2, a) - a/2` with $a=10$ is centered repetition along all three axes (Chapter 11):
$$
\mathbf q_i=\operatorname{mod}\!\Big(\mathbf p_i+\tfrac{a}{2},\ a\Big)-\tfrac{a}{2},\qquad a=10 .
$$
This tiles the scene into an infinite lattice of $10\times10\times10$ cells. Each cell is an isometric copy of the fundamental region (translation with a cut), so the repetition is **exact SDF-preserving** along each axis. One box primitive in the fundamental cell becomes an infinite grid of buildings.

### 2.2 Per-cell variation via a hash of the cell index

The building's height depends on *which cell* we're in. The cell index is
$$
\mathbf i=\Big\lfloor\frac{\mathbf p+5}{10}\Big\rfloor,
$$
and a hash `hash(i)` gives a pseudo-random value in $[0,1]$. The height is
$$
h(\mathbf i)=h_0+H\,\operatorname{hash}(\mathbf i).
$$
Each block gets a different height, so the skyline is irregular. Crucially, `h` is *constant per cell* — so the box SDF is still exact within each cell (the height is just a per-cell parameter). The uniformity of `mod` stays exact because the *map* is a per-cell isometry; only a *parameter* ($h$) varies, which does not break the distance property (the box SDF is exact for any $h$).

### 2.3 The building box SDF

$$
d_{\text{box}}(\mathbf q)=\lVert\max(\lvert\mathbf q\rvert-\mathbf b,0)\rVert+\min(\max(\lvert\mathbf q\rvert-\mathbf b),0),\qquad \mathbf b=(2,h,2).
$$
This is the exact axis-aligned box SDF (Chapter 8.3). It is $\mathcal C^0$ across edges, exact on faces.

### 2.4 Field class

| Stage | Operation | Isometry? | Class |
|-------|-----------|-----------|-------|
| repetition | `mod` | yes | exact |
| per-cell height | hash parameter | n/a (constant per cell) | exact |
| box | `sdBox` | — | exact |

So the whole city field is an **exact SDF**. This is why it renders crisp and fast — there's no smooth-min blending, no estimator, nothing that forces even a conservative step. The "infinite city" is as cheap as one box.

## 3. The "thinking process"

1. **Ideas.** "I want an infinite, irregular city." → repetition + per-cell variation.
2. **Structure.** "One block repeated." → centered `mod` along each axis.
3. **Variation.** "Irregular skyline." → a per-cell hash controlling the height.
4. **Building.** "A box." → `sdBox`.
5. **Safety.** "It's exact." → isometries + exact primitive → no special handling.

The lesson is the Chapter 11/29 core: **the complexity is generated by repetition and a per-cell parameter, not by modeling each building.** The eyes see a city; the math sees one box.

## 4. Extensions

- **Rotate each cell.** Apply a per-cell rotation (isometry) to make blocks face different directions.
- **Windows / facade.** Evaluate a periodic `cos`/`fract` pattern on the hit point's local coordinates to make a window grid — a texture, not a distance.
- **Buildings as rounded boxes.** Smoother buildings via `sdRoundedBox`.
- **Rooftop variation.** Add a second box (water tower) per cell, varied by a second hash.
- **Infinite ground + fog.** A plane plus exponential fog (Chapter 21) for atmosphere.
- **Cars / street lights.** Repeated small objects along the grid lines (still exact SDFs).
- **Intersect with a "world" box.** To make the city finite (a skyline, not infinite), crop the field to an enclosing box; this is an intersection (Chapter 9). To make it a "street canyon," subtract a slab.
